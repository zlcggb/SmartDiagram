# 折叠式分步思考耗时卡片方案

本方案旨在实现一个类似于 DeepSeek 等顶级大模型客户端的折叠式“思考过程（Thinking Process）”卡片，通过拆分 AI 处理的几个子阶段，向用户呈现精准的阶段耗时 Timeline。生成成功后进度卡片默认折叠，但允许用户点击展开并查看详情。

## 方案设计

### 1. 后端：发送结构化分步状态起止事件

在 `routes.py` 中，将 `status` 状态消息定义为含有 `step_id`、`action` (start/end) 以及展示 `content` 的结构：
- **步骤一 (router)**：分析修改意图
  - `start`: 意图路由节点开始
  - `end`: 意图路由节点结束
- **步骤二 (agent)**：分配图表专家引擎
  - `start`: 分配引擎链开始
  - `end`: LLM 开始调用
- **步骤三 (llm)**：大模型构思与生成
  - `start`: 大模型调用开始
  - `end`: 收到大模型第一个吐字 token
- **步骤四 (generating)**：图表渲染与绘制
  - `start`: 图表代码渲染开始
  - `end`: 代码生成彻底完毕 / done

---

### 2. 前端：实时维护步骤列表与耗时

在 `ChatPanel.tsx` 中的 `sendMessage` 执行流中维护一个局部步骤状态数组：
```typescript
interface ThinkingStep {
  id: string;
  label: string;
  startTime: number;
  duration?: number;
  status: 'running' | 'completed';
}
```
当接收到 `type == "status"` SSE 消息时：
- `action === 'start'`：将正在运行的步骤置为 completed，记录结束时间；然后推入新步骤。
- `action === 'end'`：将当前 id 的步骤置为 completed，计算并记录 `duration = (Date.now() - startTime) / 1000`。
更新结果使用 `updateLastAssistantMessage({ steps: [...] })` 写入消息。

---

### 3. 前端 UI：ThinkingProcess 进度 Timeline 组件

在 `ChatPanel.tsx` 中编写一个 `ThinkingProcess` 折叠卡片：
- **流式递增计时**：若处于流式思考状态，使用 `useEffect` 定时器以 100ms 刷新计算，令界面呈现“正在思考 X.X 秒”的流畅动态数字。
- **自动折叠与手动展开**：生成中默认展开；生成完毕（`done`）后自动折叠为一条小巧的耗时提示，且支持点击展开再次查看。

## Verification Plan

### 手动验证
1. 发送图表指令，观察右侧气泡最上方是否出现展开的“AI 思考过程”卡片，并展现流式运转的 Timeline 以及 0.1s 级平滑递增的计时数字。
2. 待生成完毕后，检查该思考过程卡片是否能随首字输出和完毕信号自动合拢，并且展示绿色的打勾图标以及最终总耗时（如 `耗时 12.3s`）。
3. 点击折叠栏，验证是否可以顺利展开，看清“分析修改意图”、“分配专家”、“大模型构思”等每一个单独阶段的精准执行耗时。
