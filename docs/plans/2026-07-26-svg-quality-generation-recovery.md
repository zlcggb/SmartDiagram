# SVG 质量校验与生成恢复实施计划

## 目标

修复设计稿生成已经获得模型 SVG、但被本地质量门禁拒绝并对外返回 502 的问题。继续保留严格质量门禁，同时让配方选择、生成提示、自动修复和校验规则使用同一套约束，并通过真实 `generate-design` 接口验收。

## 已确认根因

- 当前风险页的 `recommendedLayout/layoutType` 是 `risk-table`，配方选择器却因“系统/核心 + 3 个模块”的通用加分选中了 `radial-ecosystem`。
- 二次生成只收到错误文字，没有收到上一次候选 SVG，模型无法做局部、定向修复。
- 连接线校验提示允许“置于内容后方”，但实现仍把位于连接线之后的视觉锚点文字当作遮挡。
- 文本适配器会用 `textLength` 压缩甚至在单行限制下截断文本，而文字边界校验器不理解该结果。
- 质量校验失败属于可修正的内容错误，不应与模型网关失败一起映射为 HTTP 502。
- `/api/ai/status` 缺少稳定的上游异常映射，Node 服务短暂不可用时会放大成 Python 500。

## 执行步骤

### 1. 用回归测试锁定失败

- 在 `packages/agents/src/designKnowledge/designKnowledge.test.ts` 增加真实风险页语义用例，要求选择风险登记配方而不是径向生态配方。
- 在 `packages/agents/src/designKnowledge/svgSpatialQuality.test.ts` 增加连接线位于视觉锚点后方的允许用例，并保留穿越正文文字的拒绝用例。
- 在 `packages/shared/src/svgTextFit.test.ts` 增加“完整保留文字、不依赖极端 textLength 压缩、不可适配时明确报错”的用例。
- 为二次修复提示、质量错误 HTTP 映射和 AI 状态代理增加失败测试。

### 2. 增加风险页专用配方

- 新增 `risk-register` 配方：标题与结论在上，主体为 3–5 个风险卡片；仅允许顶部短细线或关键词着色，不使用附着式整高色条。
- 给 `risk-table/risk-register` 等明确布局提示设置确定性优先级，避免被通用语义分数覆盖。
- 保持其他配方原有评分逻辑不变。

### 3. 统一空间与文字规则

- 连接线仍必须位于业务内容组之前；校验穿越正文、标题和关键结论，但允许后绘制的 `visual-anchor` 覆盖底层连线。
- 文本适配优先缩小字号和正常换行，不再使用 `textLength` 强行压缩，也不静默丢字。
- 当内容在最小字号下仍无法容纳时保留完整文字，并让校验器明确报告宽度或高度超界，以便触发模型修复。

### 4. 让第二次模型调用执行定向修复

- 第一次候选失败后，把已清洗候选 SVG 和结构化问题一并传给第二次调用。
- 修复提示要求仅调整违规元素，保留正确内容、分组和视觉结构；仍保持最多两次模型调用。
- 不持久化失败候选，继续保留用户当前活跃版本。

### 5. 改善接口错误语义

- 引入可识别的 SVG 质量校验错误类型，携带结构化问题。
- `generate-design` 对质量错误返回 422，并明确提示“上一版本已保留”；上游模型或网络异常继续返回 502。
- `/api/ai/status` 将上游不可用或非 JSON 响应稳定映射为 503。
- FastAPI 代理保持无请求体的 PATCH/DELETE 真正无 body，避免 Fastify 将空分块流判定为未知媒体类型并返回 415。

### 6. 验证

- 先运行定向测试，确认新增测试由红转绿。
- 运行受影响工作区的完整测试、类型检查和构建。
- 仅在本地测试通过后，真实调用一次当前项目/页面的 `generate-design` 接口。
- 核验 HTTP 状态、页面 `generationStatus`、当前活跃版本、最近五次历史上限和模型调用记录。

## 验收标准

- 风险页不会再选中 `radial-ecosystem`。
- 连接线、文本适配和质量校验不再互相矛盾。
- 首次候选有局部问题时，第二次调用能基于原候选做定向修复。
- 质量问题返回 422；真正的上游故障才返回 502。
- 真实接口生成成功，导出仍使用当前活跃版本，历史记录不超过 5 个。
- 版本左右切换不再返回 415，切到旧版后可再切回新版，当前活跃版本与页面预览同步。
