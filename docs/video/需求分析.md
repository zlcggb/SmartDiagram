> **标准定义**：SmartDiagram 视频学习助手（`/video` 工作台，原 VidGrab 核心引擎）的系统级软件需求规格说明书（System Requirements Specification, SRS v2.7.0 · 2026-10）。  
> **生产基准**：严格对应 SmartDiagram v2.7.0 生产版本功能全集（包含 Monorepo 统一工作台、React 18 + Tailwind v4 毛玻璃交互外壳、全平台彩色徽章解析与 100% 自动流式下载、3.5s 首批字幕脉冲推流、6 线程并发 ASR 与领域先验编译器、主研报与双语翻译双线程并行、MindElixir 导图移交 `/diagram`、快慢双系统 SSE 问答、双模式 AI 测验、PostgreSQL 16 + `localStorage` 双写持久化与 Stripe 订阅支付）。

## 一、 产品定位、愿景与业务动机 (Product Vision & Stakeholders)

在信息爆炸时代，音视频（播客、公开课、技术演讲、行业访谈、研报路演）已成为知识传播的核心载体。然而，传统视频学习工具与普通转写软件存在四大致命体验短板：
1. **漫长无反馈的“盲等”与串行瓶颈**：处理视频时需完整等待数分钟，中途无字幕流输出，且主研报与字幕翻译串行阻塞；
2. **通篇泛泛的“流水账”与排版错乱**：现有 AI 总结缺乏结构化破局点，且通用 Markdown 在中文全角标点紧邻 `**加粗**` 时常解析失败，导图也无法转入专业画布深度编辑；
3. **专业领域“同音错别字”灾难**：在工业、医学、金融等垂直领域，ASR 模型频繁将专业术语转写为同音常见字，破坏知识准确性；
4. **视听、问答与测验孤岛割裂**：阅读研报或做错测题时无法一键毫秒级跳转至视频源对应画面，问答与测验记录刷新即丢。

SmartDiagram `/video` v2.7.0 致力于打造下一代工业级视频学习工作台，通过**“四点并发极速管线（210s 视频总耗时压降至 35.4s）” + “领域先验同音纠错” + “自研 `markdown.ts` 四篇章研报 & MindElixir 跨工作台导图” + “Jeff 系统 1 三层门控 SSE 问答” + “Apple Study Deck / Paper Sheet 双模式测验” + “PostgreSQL 16 & `localStorage` 双重持久化”**，重新定义视听知识获取效率。

## 四、 功能性需求全景规格 (Functional Requirements Specification - FR)

### 1. 专属导航外壳、播放器与多平台流解析规格 (FR-01)
- **FR-01-01 (专属 Apple 毛玻璃导航与 Portal 顶栏切换 `VideoShell.tsx` + `HeroInputSection.tsx`)**：隐藏模拟桌面顶栏，采用视频学习专属单行 Apple 毛玻璃导航栏；点击左侧「视频学习助手」Logo 触发 `vidgrab:reset-home` 返回首页；视频解析后通过 React Portal 将紧凑版「本地上传/在线链接」切换条嵌入顶栏正中央（`#vidgrab-navbar-center-slot`）；右侧胶囊导航包含「✨ 学习工作台」「📚 学习记录」「📖 文档中心 (`/video/docs`)」「🚀 更新记录 (`/video/changelog`)」。
- **FR-01-02 (自适应横竖屏播放器与 HTTP 206 秒级跳转 `VideoPlayer.tsx`)**：自适应竖屏（`max-w-[390px] max-h-[66vh]`）与横屏（`max-h-[54vh]`）大屏播放，支持 HTTP 206 Range 秒级精准跳转（含未播放初始态 `readyState` 校准）。
- **FR-01-03 (彩色来源徽章与 100% 自动流式保存 `VideoDownloadCard.tsx`)**：自动识别 **🎵 抖音 / 📺 Bilibili / 📕 小红书 / ▶️ YouTube / 🎵 TikTok** 等彩色来源徽章，支持清晰度下拉选择，一键下载达 100% 时自动触发浏览器流式保存（无需二次点击保存按钮），并支持 TikTok HEVC 自动转码为标准 H.264 MP4。

### 2. 四点并发极速总结管线与领域先验编译器规格 (FR-02)
- **FR-02-01 (YouTube 0.3s 字幕直通)**：命中 YouTube 视频时免下载音视频，0.3s 内直接提取官方/自动字幕。
- **FR-02-02 (FFmpeg 单步极速重采样与并发切片)**：单步抽离提取 16kHz Mono 16-bit PCM WAV 标准音频流并完成并发切片。
- **FR-02-03 (6 线程切片并发 ASR 与动态领域先验 `asr_cloud.py`)**：采用 `ASR_MAX_WORKERS=6` 并发转写，结合动态领域先验编译器（`build_asr_system_prompt`）实现零同音错别字，并通过 `on_chunk_done` 实现 3.5s 首片字幕流式回传（210s 视频转写仅需 `6.7s`）；云端异常时 100% 无缝降级至本地 `faster-whisper`。
- **FR-02-04 (主研报与双语字幕双线程并行 `summarizer.py`)**：使用 `ThreadPoolExecutor` 将主研报生成与双语字幕翻译并行执行，消除串行等待，将 210s 视频端到端总耗时从 `58.8s` 压降至 **`35.4s`**（提速 40%+）。

### 3. 六维 AI 学习面板与快慢双系统认知规格 (FR-03)
- **FR-03-01 (自研 `markdown.ts` 深度研报渲染 `SummaryPanel.tsx`)**：输出四大篇章深度研报，完美兼容 CJK 中文全角标点紧邻 `**加粗**`、单星号 `*话术示范*` 胶囊徽章，并自动将 `[阶段一] -> [阶段二]` 围栏块升维渲染为横向递进流程卡片。
- **FR-03-02 (MindElixir 交互式思维导图与跨工作台移交 `MindmapElixirCanvas.tsx`)**：基于 `markmap-lib` 解析 + `MindElixir` 胶囊树渲染，支持缩略小地图、PNG/SVG 高清导出，以及 **跨工作台一键移交 `/diagram` 画布深度编辑**。
- **FR-03-03 (双语对照字幕与时间戳联动)**：支持原文/中文双语对照展示，点击任意字幕时间戳即可驱动视频秒级跳转。
- **FR-03-04 (快慢双系统 SSE 流式智能问答 `intent_router.py`)**：系统 1 (`Jeff :8001`, `gliformer-large-v1`) 采用 Safetensors `mmap` 零拷贝低内存常驻（`685 MiB`），执行三层高置信门控（① `_SUMMARY_QA_PRIORITY_RE` 知识总结/概括硬优先白名单 ➔ ② 功能动作特征词二次校验 ➔ ③ `0.78` 高置信度阈值门控），确保引导词与开放提问 100% 归正为 `video_qa`；通过 `POST /api/ask/stream` 三阶段（`router ➔ delta ➔ done`）实时流式输出，展示 `⚡ Jeff系统1耗时 + 🧠 大模型耗时(含首字TTFT) + 🕒 HH:MM:SS`。
- **FR-03-05 (双源融合极速出题与双模式测验 `quiz_generator.py` + `QuizPanel.tsx`)**：采用时间桶均匀采样 + 研报骨架双源融合 + Bloom 四维认知分层，默认精选 6 题（单选 3 + 多选 1 + 判断 2），出题耗时从 `~25s` 降至 `~9s`；前端支持 **🎴 Apple Study Deck 闯关卡片模式**（即选即判、依据折叠、底部固定操作栏、键盘快捷键 `1-4 / Enter / ← →`）与 **📋 紧凑电子全卷模式 (Paper Sheet)**（6 题同屏流式滚动、全部/错题筛选、错题重练不丢全卷进度）。

### 4. PostgreSQL 16 双重持久化与商业化支付规格 (FR-04)
- **FR-04-01 (PostgreSQL 16 `vidgrab` 库 + `localStorage` 双写)**：后端采用 **PostgreSQL 16 (`vidgrab` 数据库)**，包含 `users`、`videos`、`analyses`（`result` JSONB 内含研报、`chat_history` 多轮问答、`quiz_data` 测验与作答状态）、`quizzes`、`quiz_attempts` 表，配合前端 `localStorage` 实现游客与登录用户的全链路双重持久化。
- **FR-04-02 (学习记录中心 `VideoHistoryPage.tsx`)**：实时展示历史分析卡片与 `🎯 测验 XX分` 徽章，点击即可一键回放并恢复完整研报、对话与测验状态。
- **FR-04-03 (Stripe 托管收银台与 Webhook 幂等)**：支持 `bcrypt` 加盐鉴权与 JWT 令牌，集成 Stripe Checkout 月付/年付订阅及 `billing_webhook_events` 幂等落库。

| **持久化 (Storage)** | 全链路历史与状态 | 双写零丢失 | 刷新页面与跨会话恢复测试 | PostgreSQL 16 (`vidgrab` 库 JSONB) + `localStorage` 双写 |
