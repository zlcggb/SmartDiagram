## Webhook Secret 写入环境变量

`stripe listen` 成功后，将终端里的 `whsec_...` 写入用户环境变量：

```powershell
[Environment]::SetEnvironmentVariable(
  "STRIPE_WEBHOOK_SECRET",
  "whsec_粘贴终端输出的完整字符串",
  "User"
)
```

## PowerShell 注意

- 用 `powershell -File scripts\xxx.ps1`，不是 `pwsh`（除非已装 PowerShell 7）
- 若报 `running scripts is disabled`：用 `stripe.exe` / `.bat`，或  
  `Set-ExecutionPolicy RemoteSigned -Scope CurrentUser`
