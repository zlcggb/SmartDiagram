## 一、 业务背景与反爬风控现状 (Background & WAF Landscape)

流媒体知识提取系统最脆弱的生命线是数据源站的可用性。近年来，各大主流视频平台（抖音、B站、小红书、YouTube、X）全面升级了针对数据中心 IP 与爬虫自动化工具的 Web 应用防火墙（WAF）：
1. **状态码风控（HTTP 412 / 403）**：B站与小红书对缺乏特定设备签名或 TLS 指纹异常的 HTTP 请求直接下发 412 Precondition Failed；
2. **交互式验证码阻断**：频繁访问触发极验、阿里滑动拼图或 Cloudflare Turnstile 验证码；
3. **协议混淆与 PO Token 校验**：YouTube 对非住宅 IP 部署 SABR 协议与 Bot 封锁，强制校验 Client Integrity 凭证。

许多同类工具选择“将难题甩给用户”，强制要求普通用户按 F12 打开开发者工具抓取个人 Cookie 上传，这不仅造成巨大的体验摩擦，还存在用户隐私凭证泄露的合规隐患。VidGrab 确立了**“用户完全无感（Zero-Hassle）”**的最高工程宗旨：依托服务端自动化匿名 Cookie 池与轻量开源签名服务，抹平反爬摩擦。

   - 提取真实 `http://` / `https://` 链接，过滤移动端分享文案；
   - 清理所有分析埋点参数（`utm_*`, `spm`, `from` 等），保留核心安全凭证（如小红书 `xsec_token`）。
2. **第二步：实现专用薄适配器 (`apps/api-video/extract_<platform>.py`)**
   - 仅实现元数据抽取与无水印直链解析；
   - 返回统一的 `MediaExtractResult` 对象；
   - **严禁**自行在适配器内部实现重复的视频下载或文件写入逻辑。
3. **第三步：注册入主干管道 (`apps/api-video/downloader.py`) 与前端徽章映射 (`apps/web/src/features/video/`)**
   - 适配器输出的直链直接喂给 `chunked_downloader.py`（4 线程 Range 并发加速）；
   - 在 `classify_error()` 中注册该平台的专属错误码（如 `account_private`, `region_locked`）；
   - 前端视频卡片自动匹配 **🎵 抖音 / 📺 Bilibili / 📕 小红书 / ▶️ YouTube** 等彩色平台徽章，并在下载进度达到 `100%` 时自动触发 `/video-api/api/file/{task_id}` 浏览器流式保存，消除二次确认点击。

## 五、 边界防御、Cookie 池安全与高可用治理 (Defensive Mechanisms & Reliability)

### 1. 连续 412 熔断冷却机制
当某个爬虫工作节点对同一平台连续出现 3 次 HTTP 412 时，触发局部熔断保护（Circuit Breaker）：
- 挂起该平台的自动请求 60 秒；
- 避免因死循环重试导致数据中心公网 IP 被平台拉入黑名单（Ban IP）。

### 2. 匿名 Cookie 安全沙箱
系统持有的匿名 Cookie（`platform_cookies.json`）仅存储低权限的公共游客会话，绝对不包含任何已登录用户的真实身份与账户信息：
- 运行时禁止向日志文件打印包含完整 Cookie 字符串的调试日志；
- 定期由守护协程向源站静默刷新并更新 `updated_at` 时间戳。

### 2. 常见反爬异常与紧急排障矩阵

| 异常现象 | 核心根因 | 生产排障步骤与自愈手段 |
| :--- | :--- | :--- |
| **B站 412 Precondition** | WBI 签名密钥过期或匿名 Cookie 失效 | 重启后端触发 `platform_cookies.py` 重新生成游客 Session |
| **小红书 406 Not Acceptable** | URL 中遗失了 `xsec_token` 参数 | 检查前端是否截断了分享链接，必须复制包含 Token 的完整地址 |
| **YouTube 429 Sign-in** | 数据中心 IP 触发 Bot 封锁 | 检查 Node.js PO Token 服务是否正常运行，或轮换海外代理节点 |
| **抖音无水印解析失败** | 抖音 Web 端分享页 DOM 结构微调 | 更新 `douyin.py` 中的 JSON 路径匹配规则 |
