# 工作台流媒体播放、秒级空降与一键自动保存架构白皮书 · Media Playback & Download Architecture

> **标准定义**：SmartDiagram 视频学习工作台 (`/video` v2.7.0) 音视频流媒体代理播放、防盗链穿透、平台彩色来源徽章、HTTP 206 秒级精准空降 (`seekTo`) 与一键流式自动保存下载技术白皮书。  
> **生产基准（SmartDiagram v2.7.0 · 2026-10）**：基于 **React 18 + TypeScript (`VideoPlayer.tsx` / `VideoDownloadCard.tsx` / `VideoWorkspacePage.tsx`) + FastAPI 流式代理网关 (`media_routes.py`) + Nginx `proxy_buffering off` HTTP 206 Partial Content 分片响应 + 100% 完成自动触发浏览器原生保存 (`triggerBrowserFileDownload`)** 构筑的工业级交互体系。

## 一、 业务背景与多端播放壁垒 (Background & Playback Barriers)

SmartDiagram 视频学习助手的核心交互范式是“**边看视频、边读研报、随心空降、一键留存**”。用户在四大篇章研报结论、时间轴导览、双语对照字幕或 AI 测验解析中，点击任意时间胶囊（如 `▶ 00:26` 或 `【02:45】`），左侧播放器必须在 **$\le 100\text{ms}$** 内完成毫秒级精准定位跳转并立即起播。

然而，在公网开放流媒体环境下，直接请求第三方平台流媒体面临四大致命技术壁垒：

## 四、 前端组件设计与交互升级详解 (`VideoPlayer.tsx` & `VideoDownloadCard.tsx`)

### 1. 左侧播放器自适应大尺寸与竖屏识别 (`VideoPlayer.tsx`)

## 五、 边界防御、HTTP 206 穿透与未播放初始态校准 (Edge Defense & Range Calibration)

### 1. 网关级防盗链头伪装与 HTTP 206 透传 (`apps/api-video/media_routes.py`)
针对抖音、B站、小红书及微博等防盗链 CDN，`/api/media/proxy/{token}` 动态注入目标源站所需的 `Referer` 与 `User-Agent`，并透传浏览器的 `Range` 请求头：
```python
headers = dict(entry.get("headers") or {})
range_header = request.headers.get("range")
if range_header:
    headers["Range"] = range_header
```
同时將上游返回的 `206 Partial Content`、`Content-Range`、`Accept-Ranges: bytes` 与 `Content-Length` 原样流式转发给前端 `<video>`。

### 2. Nginx 反向代理零缓冲配置 (`proxy_buffering off`)
在生产环境 Nginx 网关中，针对 `/api/media/` 路由显式配置 `proxy_cache off; proxy_buffering off;`，防止 Nginx 吞掉 `Range` 头或将分片响应缓冲为 `200 OK` 全量流，确保 HTTP/2 下 `206 Partial Content` 秒级直达浏览器。

### 3. 未播放初始态 (`readyState < 1`) 延迟跳转校准
当用户刚打开页面尚未点击播放（此时 `<video>` 的 `readyState === 0`）就直接点击研报中的 `▶ 00:26` 时间胶囊时，直接赋值 `v.currentTime = 26` 会被部分浏览器忽略。`VideoPlayer.tsx` 针对未就绪状态注入 `loadedmetadata` / `canplay` 一次性监听器延迟校准，并在就绪后立即执行 `v.currentTime = t; v.play()`，确保任何时刻点击时间胶囊均能 100% 精准空降。
