## 一、背景

在 TikTok HEVC 播放缓存、无旁白画面分析（方案 A/E）、工作台 xgplayer 等能力落地后，早期版本曾收到如下反馈：

1. YouTube 播放器只显示 **Piped** 徽标、一直转圈  
2. AI 总结 **卡在 62%**，11 分钟视频极慢  
3. B 站 AI 总结 **CDN 超时**  
4. 「性能优化」后 **下载区消失**、解析一直「处理中」  
5. 怀疑改动未遵循项目既有开源方案（Piped / xgplayer / SenseVoice 等）

通过 **B+ 稳态修复** 与后续 **v2.7.0 四点并发加速迭代**，系统不仅彻底根除了上述回归问题，还将无字幕视频的云端 ASR 与总结全链路速度提升了 **40%+**。

## 八、工程铁律（后续必守）

1. **改 `media_playback` / `_recover` 必须全平台回归** — TikTok 与 YouTube 共用 yt-dlp 恢复链，签名不对会静默失效。  
2. **国内 CDN（B 站 mcdn）必须直连** — 请求级 `proxies=None` + `NO_PROXY`。  
3. **缓存只存成功** — 失败不传染并发请求。  
4. **YouTube 总结慢 ≠ Key 未配** — 先看 `transcript_source`；bot 校验导致无字幕才会落 ASR。  
5. **主研报与双语翻译保持并行** — 在 `summarizer.py` 中通过 `ThreadPoolExecutor` 并行执行，严禁退回串行阻塞。  
6. **公共 Piped 实例不稳定** — 播放可见兜底用 **YouTube 官方 embed**，不用 `piped.video`。
