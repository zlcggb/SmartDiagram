## 经验

- **部署类教程**应先写「路径选择 + 总流程」，再写逐步命令，避免把可选方案（宝塔静态托管）放在开头
- **Word 教程**适合「一级章节 = 阶段、二级 = 步骤、代码用等宽字体块」，截图紧跟在「期望结果」之后
- 国内 ECS 文档应把 **git clone 失败 → zip 上传** 作为并列方案 B，而非埋在段落中间
