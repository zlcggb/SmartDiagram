# 🎯 AI 视觉分析教练与端云协同架构白皮书 · Embodied Visual Coach Architecture

> **模块路由**：`/video/coach`（探索别名 `/video/coach-lab`）  
> **版本基准**：`v2.8.0 (2026-10-25)`  
> **核心定位**：基于 **「浏览器端 WebAssembly + WebGL 三合一高精度生物力学感知（全身 33 点 + 双手 42 指关节 + 面部 478 点 3D 网格） + 2×2 时序四格拼图压缩 + Gemini 3.5/3.8 Flash SSE 流式视觉教练 + 一键转化为复盘研报/导图/测验闭环」** 的零服务端 GPU 算力视觉教练系统。

## 一、 核心破局思路与三步计算架构

传统实时视频 AI 分析若将 30fps 视频流直接推流至云端 GPU 跑姿态识别与多模态大模型，不仅网络带宽高、延迟大（`>5s`），且服务端需要昂贵的 GPU 实例。SmartDiagram 采用 **「端云算力解耦」三步破局法**：

1. **Step 1 · 端侧零成本高精度感知（Browser GPU · 30fps）**：
   - 在用户本地浏览器通过 Google MediaPipe Tasks Vision（WebAssembly + WebGL GPU Delegate）实时运行三大高精度模型：
     - **全身骨骼（`pose_landmarker_full.task`）**：33 个 3D 全身骨骼关键点，实时解算双肩水平倾角、左右肘夹角、左右抬臂角、躯干前倾角与膝关节角。
     - **双手 21×2 指关节（`hand_landmarker.task`）**：左右手共 42 个精细指骨关节，实时计算五指伸展度与手势语义（五指张开、握拳、单指指向、托腮、抱头等）。
     - **面部 478 点 3D 网格 + 52 维表情（`face_landmarker.task`）**：实时解算头部 3D 朝向（转头 Yaw / 俯仰 Pitch / 歪头 Roll）与表情肌状态（微笑、张嘴说话、挑眉、眨眼）。
   - **自适应视野过滤（Visibility Gating）**：仅对真实入镜且置信度达标的身体部位计算角度并喂给大模型，彻底杜绝半身入镜时大模型“瞎编下肢动作”的幻觉。
2. **Step 2 · 2×2 时序四格拼图 + 帧间运动门控（Temporal Grid + Motion Gate）**：
   - 将一个时间窗口（`2.5s` 极速流或 `4.0s` 标准流）内采集的 4 帧连续关键画面合成为单张 `960×540` 的 **2×2 时序网格图（左上 #1 → 右上 #2 → 左下 #3 → 右下 #4）**，请求体积从多图 `160 KB` 压降至 **`~22 KB`**（降低 **86%**），并赋予单次 VLM 调用完整的动作时序方向感。
   - **帧间像素差分门控（`FrameDiffGate`）**：当画面静止（`Δ < 1.0`）时自动跳过云端大模型请求，节省 **50%+** 无效 Token 消耗。
3. **Step 3 · 视觉大模型流式纠偏 + 训练复盘闭环（VLM SSE + Review Closed-Loop）**：
   - 后端 FastAPI（`apps/api-video/coach_lab/`）将 **2×2 连续帧拼图 + 端侧实测骨骼/手势 JSON + 滚动历史记忆** 注入 `Gemini 3.5 Flash Lite` 或 `Gemini 3.8 Flash High`，通过 SSE 实时流式返回动作定性、量化角度锚点与教练纠偏口令。
   - 点击 **「🚀 一键生成完整复盘研报与导图」**，自动将分段动作记录合入 `/video` 标准管线，生成结构化深度复盘报告、MindElixir 动作拆解导图（可一键移交 `/diagram` 画布）与 6 题互动测验。

## 二、 线上部署与三级缓存加速架构（服务端 0 GPU 成本）

### 2.1 模型体积与 Gzip 传输实测表

所有视觉模型均作为纯静态文件托管于前端 `apps/web/public/mediapipe/` 目录，由 Nginx 开启 `gzip_static` 与 `Cache-Control: public, max-age=31536000, immutable` 分发：

| 静态资产文件 | 作用说明 | 原始大小 (Raw) | **Gzip 实际传输大小** | 首次加载后二次访问 |
| :--- | :--- | :---: | :---: | :---: |
| `vision_bundle.mjs` + `wasm/*` | MediaPipe WebAssembly + WebGL 推理运行时 | `9.38 MB` | **`2.85 MB`** | **`0 MB`**（本地命中） |
| `pose_landmarker_full.task` | 全身 33 点 Full 高精度骨骼姿态模型 | `8.96 MB` | **`7.97 MB`** | **`0 MB`**（本地命中） |
| `hand_landmarker.task` | 双手 42 点（每手 21 点）指关节手势模型 | `7.46 MB` | **`5.58 MB`** | **`0 MB`**（本地命中） |
| `face_landmarker.task` | 面部 478 点 3D 网格 + 52 维微表情模型 | `3.58 MB` | **`3.18 MB`** | **`0 MB`**（本地命中） |
| **合计（WASM + 三合一模型）** | **全身 + 双手 + 面部全量开启** | **`29.38 MB`** | **`19.58 MB`** | **`0 MB`（耗时 `< 150ms`）** |

### 2.2 为什么服务端完全不需要 GPU？

1. **视频流与骨骼/手势/面部识别 100% 运行在用户终端显卡（电脑/手机浏览器 WebGL）**：原始摄像头视频流不上传服务器，服务端 CPU/GPU 负载为 **0**。
2. **自建同源静态托管 + 浏览器 `CacheStorage` 永久持久化**：
   - 模型文件直接随前端构建产物部署在自有服务器 `/mediapipe/` 路径下，国内及全球用户直连下载，彻底消除对 Google 海外 스토리지（`storage.googleapis.com`）的网络依赖。
   - [`edgePerceptionEngine.ts`](/apps/web/src/features/video-coach-lab/lib/edgePerceptionEngine.ts) 在模型就绪后自动将 `.task` 权重写入浏览器 `window.caches.open('smartdiagram-mediapipe-models-v1')`，后续刷新或重开页面实现 **`0 MB` 网络流量、`< 150ms` 瞬时启动**。

## 三、 交互状态机与算力风控保护设计

### 3.1 互斥二选一输入源 + 一气呵成自动分析状态机

- **待机二选一态（`sourceType === null`）**：
  - 界面去除一切置灰冗余按钮，仅展示 **「📷 开启镜头实时分析」** 与 **「📁 选择视频实时分析」** 两个互斥主入口。
- **活跃会话态（`sourceType === 'camera' | 'file'`）**：
  - **开启即自动分析**：点亮摄像头或选定本地视频的瞬间，自动进入连续抽帧与大模型流式诊断，无需二次点击「开始分析」。
  - **彻底隐藏另一输入源防误触**：开启镜头后彻底隐藏「选择视频」按钮（反之亦然），操控栏切换为当前会话专属三键：**`⏸ 暂停分析 (0ms)` ↔ `▶ 继续实时分析`**、**`⚡ 立即抓拍`**、**`🔴 关闭镜头 / ✕ 退出视频`**。
  - **0ms 瞬时截断**：基于 `AbortController` 毫秒级切断正在进行的 SSE 流，关闭摄像头时同步调用 `MediaStreamTrack.stop()` 物理断电。

### 3.2 桌面端双向独立滚动与移动端原生 4-Tab 教练工作台

- **桌面端（`>= 1024px`）**：左右分栏锁定视口高度（`h-full overflow-hidden`），左栏（取景器 + 操控坞 + 实时生物力学 Bento）与右栏（场景切换 + 流式诊断卡片列表）各自拥有独立滚动容器（`overflow-y-auto`），翻阅几十段历史诊断时左侧实时画面永不滚出视野。
- **移动端（`< 1024px`）**：
  - 进入 `/video/coach` 时自动隐藏通用「视频学习助手」底栏与双层顶栏，切换为 **AI 视觉教练专属工作台**。
  - **上半屏常驻取景**：单行极简顶栏（含返回键与实时配额胶囊）+ 16:9 视频取景器（右上角内嵌悬浮 `🦴身体 / 🖐️双手 / 😊面部` 图层胶囊，左上角支持手机 `🔄 前置/后置` 镜头翻转）+ 紧贴视频下方的拇指操控坞。
  - **下半屏独立滚动 + 专属 4-Tab 底栏**：**`💬 实时诊断`** | **`🎯 骨骼/手势数据`** | **`✏️ 教练与提示词`** | **`🚀 复盘报告`**。

### 3.3 单次防呆自动熔断与访客/登录分级每日配额

为防止用户忘记关闭摄像头或恶意刷取导致大模型算力浪费，前后端（[`VideoCoachLabPage.tsx`](/apps/web/src/features/video-coach-lab/pages/VideoCoachLabPage.tsx) + [`coach_lab/routes.py`](/apps/api-video/coach_lab/routes.py)）实施双重计时风控：

| 用户身份 | 单次连续分析上限 | 全天（自然日）累计上限 | 熔断保护机制 |
| :--- | :---: | :---: | :--- |
| **👤 访客模式（未登录）** | **`1 分钟`（`60s`）** | **`5 分钟`（`300s` / 天）** | 单次满 1 分钟自动 `0ms` 暂停分析；全天累计满 5 分钟（前端 `localStorage` + 后端客户端 IP 双重计量）立即锁定当日免费额度并弹出 **「🔑 立即登录解锁」** |
| **🛡️ 已登录用户** | **无操作 `2 分钟`（`120s`）自动暂停** | **`15 分钟`（`900s` / 天，管理员不限）** | 连续 2 分钟无任何交互操作时自动 `0ms` 暂停分析，防止离开座位忘记关闭造成 AI 资源消耗；有主动操作时自动重置 2 分钟防呆计时器 |
