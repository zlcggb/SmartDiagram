# 经验：IR + SVG 混合导出优化方案怎么写才可并行落地

## 场景

已有多份调研（架构评审、Hybrid 策略、参考仓分析、PRD），需要产出一份让其他 Agent **并行改代码** 的优化方案，而不是空泛路线图。

## 做法

1. 先统一终态选型（Hybrid），并写清与「IR-first 评审结论」的关系，避免执行时摇摆。
2. P0 必须写到 **字段名、枚举、伪代码、改哪些包、谁先合并**。
3. 明确禁止行为（如「有 SVG 编译失败就整份 throw」），比只写「要支持降级」更可验收。
4. 单独列出并行冲突面（schema、renderer 中心函数、API 400 门禁）。

## 可复用点

- AI 生成链路优化：契约硬化优先于换栈。
- 多 Agent 并行：shared 契约单一写入者，其余只消费。
