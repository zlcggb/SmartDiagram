# 演讲稿、配音与视频导出

## 目标

在现有 PPT 项目上增加一条可编辑、可重试的媒体生产链路：逐页演讲稿 → TTS 配音 → 按音频时长合成 1080p MP4。

## 实现范围

- Prisma 新增 `SlideNarration` 和 `MediaExport`，保存逐页讲稿、音频与视频任务状态。
- Node API 新增媒体运行时检查、讲稿生成/编辑、单页及批量 TTS、视频导出接口。
- TTS API Key 只保留在服务端；二进制 MP3 落盘后读取真实时长。
- 复用 SVG 渲染器产生逐页 PNG，由 FFmpeg 生成 H.264/AAC 分段并无损拼接。
- Web 端“导出历史”页新增“演讲视频”区域，可编辑讲稿、播放配音、生成并下载视频。

## 关键决策

- 第一版讲稿从已定稿的页面标题、核心结论和内容点结构化生成，以可预测和可编辑为先；后续可在此基础上增加 LLM 润色。
- 页面内容或讲稿变更后，旧配音会失效，防止文字与声音不一致。
- 导出文件沿用 `storage/exports` 和现有 `/exports/*` 静态下载路由。

## 验证

- Prisma migration / generate 通过。
- 全工作区 TypeScript typecheck 通过。
- SVG 编译回归测试通过。
- 网关 `/api/media/status` 真实检测到 TTS 配置与 FFmpeg。
- 真实 TTS 生成单页 54.1 秒 MP3。
- 媒体冒烟链路生成 1920×1080 H.264/AAC MP4，并由 `ffprobe` 核验。
- Playwright 打开真实项目导出页，确认运行时就绪、讲稿编辑与配音状态正常，控制台无错误。

## 配音风格增强（2026-07-20）

- 新增“配音导演台”，可选择专业清晰、娇甜撒娇、轻柔轻声、明亮博主四种风格。
- 音色列表从 TTS 服务 `/v1/tts/models` 动态获取，当前服务返回 8 种可用音色。
- 支持基础音色、表演强度和导演提示的组合调整，并支持短句试听、应用到全部页和单页重配。
- 使用 `Leda` 娇甜风格、`Aoede` 轻柔风格与 `Zephyr` 明亮风格进行真实 TTS 试听验证。
- 实测确认过度堆叠耳语/呼吸类描述可能被上游用量规范拦截，因此内置预设使用更稳定的“轻声、柔和、轻盈共鸣”表达。
- 项目顶部导航在“工作室”右侧新增“导演”入口，路由为 `/p/:projectId/director`，该页只渲染配音与视频导演内容；`/p/:projectId/exports` 单独保留 PPTX 导出历史，两个页面不再混合。

## TTS 受控并发（2026-07-20）

- 批量配音从原来的逐页串行调用改为受控并发池，默认 3 路，最大 5 路。
- 导演台可选 1–5 路并发，批量生成配音和视频导出时自动补配音共用该设置。
- 并发池会等待全部任务收敛，单页失败不会中断其他正在生成的页面，最后统一汇总失败页码。
- `smoke:concurrency` 验证 9 个任务在 3 路上限下全部被处理，峰值并发严格为 3，且失败任务能正确汇总。

## 视频预览与附件下载（2026-07-20）

- 视频导出历史中将“预览”和“下载 MP4”拆分为独立操作：预览使用静态视频 URL 在页内弹窗播放，下载走项目和导出记录双重校验的 API。
- 下载接口返回 `Content-Disposition: attachment`，同时提供 ASCII 和 UTF-8 文件名，确保跨端口开发环境中也触发浏览器下载，不再跳转到视频播放页。
- 真实网关响应已验证为 `200 OK`、`video/mp4`、`attachment` 和正确 `Content-Length`；Playwright 验证预览弹窗可播放，点击下载后仍停留在导演页并产生浏览器下载事件。

## 可选烧录字幕（2026-07-20）

- 导演台新增“烧录中文字幕”开关与字体选择；开启时导出硬字幕 MP4，关闭时沿用无字幕链路。
- `apps/api/assets/fonts/NotoSansCJKsc-Regular.otf` 及其 SIL Open Font License 1.1 许可证作为 API 运行资产管理，启动时会自动复制到 `storage/fonts`，字体不需要安装到操作系统。
- 字幕按讲稿标点分段，依据每页真实配音时长按字符权重分配时间，自动生成全片 SRT。
- 由于当前 Homebrew FFmpeg 未编译 `libass`/`drawtext`，字幕改为用 Resvg 与指定 OTF 渲染透明 PNG，再通过 FFmpeg `overlay` 按时间烧录，不依赖系统字体与 libass。
- 视频导出历史显示“带字幕/无字幕”，带字幕记录同时提供 MP4 和 SRT 附件下载。
- 真实样片验证为 1920×1080 H.264/AAC、总时长 502.18 秒，同名 SRT 正常生成；Playwright 验证字幕开关、字体禁用联动、历史状态与 SRT 浏览器下载。

## 紧凑字幕样式库（2026-07-20）

- 默认字号从 48px 降到 34px，使用单行长字幕和更大的底部安全边距，避免字幕抢走 PPT 内容的视觉重心。
- 导演台新增“轻描边”、“柔和胶囊”、“品牌强调”三种可选样式；默认轻描边无底板，对画面遮挡最小。
- 单条字幕默认最长约 36 个中文字符，超出后切换到下一条；胶囊底板按实际文字宽度自适应，宽度上限放宽到画面的 82%。
- 共享数据契约、API 导出参数、导出记录与 PNG 字幕渲染链路已全部打通，旧请求未提供样式时自动回落到轻描边。
- 同一张真实 PPT 帧已生成三种对比图；单元测试覆盖样式结构、默认值、宽度上限和视频底部定位。
