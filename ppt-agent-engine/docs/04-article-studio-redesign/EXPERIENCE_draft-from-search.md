# EXPERIENCE · 检索 → 初稿必须是真递进，不能同输入复述

## 何时复用

- 多阶段 AI 流水线（检索 / 大纲 / 初稿 / 设计）
- UI 文案写「基于上一步」，但模型入参没接上一步产物
- 用户觉得「步骤很多但每步都在重复同一份字段」

## 根因模式

1. **System prompt 承诺了资料卡，User prompt 没塞资料卡**  
2. **Mock 为了能跑，直接 echo `contentPoints`**，掩盖断链  
3. **UI 在下一步继续编辑上一步输入**（页意图），主结果却不可编辑 → 用户以为下一步没做事

## 推荐套路

| 步骤 | 输入 | 输出 | UI |
|------|------|------|-----|
| 检索 | 页意图 | `searchJson` 资料卡 | 可勾选「用于下一步」 |
| 初稿 | 已选资料卡 + 页意图 | `planJson` 可编辑正文 | 页意图只读；正文可编 |
| 设计 | `planJson` | SVG/IR | 改初稿应失效旧设计 |

实现检查清单：

- [ ] 下一步 prompt JSON 里能看到上一步产物  
- [ ] Mock 路径也走同一套「综合」逻辑，禁止只 echo  
- [ ] 「用于 xxx」勾选是受控写入，不是 `readOnly` 摆设  
- [ ] 可编辑的是本步产物，不是上一步输入字段

## 反模式

- 三步 UI，一份字段编辑三遍  
- checkbox `defaultChecked` + `readOnly`  
- 有 `searchJson` 字段却从不进 `generateSlidePlan`
