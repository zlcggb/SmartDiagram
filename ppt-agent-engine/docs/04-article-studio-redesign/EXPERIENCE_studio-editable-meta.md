# EXPERIENCE · Studio 页元信息可编辑

日期：2026-07-17

## 场景

凡「先建空白页 / 大纲占位页，再检索或生成」的工作流，搜索/初稿阶段必须能改 `title`、`keyMessage`（及可选 `contentPoints`），且动作前要保证已落库。

## 可复用做法

1. **展示与编辑同源**：搜索 Tab 不要用静态 `<h2>` 展示 slide 字段；与初稿共用表单组件。
2. **本地草稿 + debounce/blur**：不要每键打 `updateSlide`；检索/生成按钮点击前 `flush`。
3. **字段保存勿占全局 busy**：否则输入过程会禁用「重新搜索」等主操作。
4. **后端已读 DB slide**：前端保证保存顺序即可，无需在 search body 再传标题。

## 反例

- 仅在弹窗里改元信息 → 空白页落地页仍像只读，转化差。
- 只修初稿 Tab、不修搜索 Tab → 用户卡在检索入口。
