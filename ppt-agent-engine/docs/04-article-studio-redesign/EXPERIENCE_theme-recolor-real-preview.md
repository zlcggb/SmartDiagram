# EXPERIENCE · SVG 主题「真换色」预览

## 何时复用

- 产品承诺「切换主题即换色、无需重生」，但稿面颜色是 AI **写死的 `#hex`**
- 用户投诉「换色是假的」：侧栏选中变了，中心大色块几乎不动
- 预览与导出必须同色（同一 `recolorSvgPreview`）

## 根因模式

1. **只认精确 token**：AI 常用 Tailwind 蓝（`#1E3A8A`、`#2563EB`），近邻阈值过严 → 漏换  
2. **source 主题误判**：只看背景矩形，纯白底像 `chart-report`/`glass`，再用错色板做角色匹配  
3. **文案超卖**：算法失败时 UI 仍写「无需重新生成」→ 信任崩塌  
4. **质感 ≠ 色板**：CSS `filter` 不能冒充 ThemePack 换色

## 做法

1. **全库色票 + 启发式**：跨 ThemePack 匹配角色；饱和色兜底为 `accent`  
2. **检测要投票**：背景 + 全稿 hex，不要单点 bg  
3. **纯白按目标族分流**：浅 → `bg`，深 → `onAccent`  
4. **文案对齐能力**：写「改色板即时；版式大变再生成」，不要写绝对「无需生成」  
5. **预览导出同源**：禁止只给 iframe 换色、导出仍用库存 SVG

## 反例

- 只改侧栏选中态 / 外框背景色，不动 SVG 内 fill  
- 发现换色弱就先改文案掩饰，不修映射  
- 把 surface filter 当成「换了主题」
