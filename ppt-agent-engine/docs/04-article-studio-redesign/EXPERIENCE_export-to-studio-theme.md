# EXPERIENCE · 导出配置进预览侧栏

## 何时复用

- 导出 / 主题 / 视觉等级 与「预览」拆成两页，用户来回跳
- 产品要从「专家模式（mode × strategy）」收敛成「主题 + 一键导出」
- 并行改同一 Studio 页时，需保留他人刚加的可编辑表单

## 做法

1. **历史与生成拆页**：历史列表不承载配置；配置贴在预览旁，下载即时反馈。
2. **mode 藏后端**：API 字段可留；UI 固定 `standard`，差异靠每页 `renderStrategy`。
3. **主题要像控制面板，而不是重新生成**：AI SVG 色值是写死的，做不到真·CSS 变量；用 `recolorSvgPreview` 按角色色板近似映射，预览与导出即时换色、库存 SVG 不改（可逆）。AI「重新生成」只留给布局级主题差异。
4. **策略只读**：策略在大纲/生成阶段已定，设计稿再切会打乱预期；改成徽章。
5. **日志降级**：设计稿右栏优先主题/导出；日志折叠或放到搜索/初稿。
6. **合并冲突意识**：改 Studio 前先读全文件；搜索 Tab 的 meta 编辑器与 debounce 保存不要被主题栏改动冲掉。

## 反例

- 导出页仍放三个 mode 卡片 → 与「策略已定」叙事冲突
- 切主题不重生成 SVG → 预览与导出不一致
- 用「去导出」代替一键导出 → 多一次跳转且历史页无生成入口
