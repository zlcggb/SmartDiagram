# EXECUTION · Studio 中间栏内滚（检索长结果）

日期：2026-07-18

## 需求

检索素材生成后，结果卡片 + 摘要很长，中间栏没有有效高度上限，虽然写了 `overflow-y-auto`，但仍把整页撑高，浏览器整体滚动，顶栏/步骤条被顶走，「进入初稿」也要滚到底才看得见。

## 方案对比

| 方案 | 做法 | 权重（满分 10） | 说明 |
|------|------|----------------|------|
| A | 中间栏单独加 `max-h-[70vh]`，与左右栏旧写法对齐 | **7.5** | 改动最小；CTA 仍可能滚出视野；三列高度不统一 |
| B | 大屏三列共锁 `100dvh - 顶栏预算`，栏内 `min-h-0` + 内滚；下一步条 `sticky bottom` | **9.0** | 整页不再被撑开；下一步按钮始终可见；检索/初稿/设计稿一致 |

**选用方案 B。**

## 改动

1. `StudioPage.tsx`
   - `.studio-columns`：`lg:h-[calc(100dvh-12.5rem)]` + `lg:items-stretch`
   - 左栏 / 中间栏 / Agent 日志：移动端各自 `max-h`，大屏 `lg:h-full lg:min-h-0` + `overflow-y-auto`
   - 检索、初稿完成条：`sticky bottom-0` + 半透明底，贴在中间栏滚动容器底部
2. `ThemeConfigPanel.tsx`
   - 侧栏改为跟随父列高度（`lg:h-full`），避免设计稿阶段仍用孤立 `70vh`

## 验证

- [ ] 检索有多张结果卡时：中间栏出现纵向滚动条，页面主体几乎不滚
- [ ] 滚动结果时：「进入初稿 →」仍贴在中间栏底部可见
- [ ] 切换初稿长内容：同样内滚 + sticky「进入设计稿」
- [ ] 设计稿 + 主题侧栏：三列等高，侧栏内部可滚
- [ ] 窄屏：仍可分段滚动，不出现三列被压成一条不可用缝
