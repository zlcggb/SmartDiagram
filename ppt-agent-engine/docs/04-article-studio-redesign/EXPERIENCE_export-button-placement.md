# EXPERIENCE · 一键导出放工具条，历史走顶栏

## 何时复用

- 侧栏同时堆「配置 + 主 CTA + 历史入口」，用户标注要把下载挪到预览区工具条
- 顶栏已有「导出历史」Tab，工具条/侧栏再放「导出历史」造成三入口重复

## 做法

1. **主下载 CTA 跟预览工具条**：一键导出与「生成本页/全部设计稿」同簇，右上角一眼可见。
2. **历史只保留顶栏（+ 导出页本身）**：删工具条/侧栏重复 Link。
3. **重生跟主题侧栏**：按主题重生会改构图，语义贴配置区，不要跟下载挤一排。
4. **搬家不丢参数**：按钮只换挂载点；`exportPptx()` 继续从 store 读 `exportTheme` / `themeAccentId`。

## 反例

- 把导出 + 双重生整组塞进工具条 → 按钮簇拥挤，重生与主题配置脱节
- 只挪按钮却改成写死 theme → 侧栏换色后导出仍是旧主题
