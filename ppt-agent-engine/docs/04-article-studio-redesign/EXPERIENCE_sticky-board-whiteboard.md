# 经验：便利贴墙要用「白板混排」而不是「大纲列表」

## 场景

把大纲画成「深蓝章节条 + 下方单列卡片」时，用户会立刻说「不是这么放的」——他们期待的是 Miro/FigJam 式**点阵画布 + 章节卡与内容卡同级平铺**，而不是文档目录。

## 可复用做法

1. **章节是合成卡，不是色条**：用 `partTitle` 变化插入 SECTION 卡（大字号 + 淡色编号 + Draft），与内容卡进同一 CSS `columns` / grid 流。
2. **先做多列混排，别上自由坐标**：无 x/y 持久化也能对齐 80% 参考图；自由拖拽放到下一期。
3. **选中态与进工作室分流**：单击选中（工具条删/加页），标题或阶段图标再进 Studio，避免「一点就跳走」没法批量整理。
4. **Contents 侧栏低成本**：只列章节名 + `scrollIntoView`，不必做虚拟视口。

## 注意

- 避免紫渐变霓虹；品牌蓝边框/工具条即可。
- `createBlankSlide` 默认追加末尾时，工具条「新增」需再 `reorderSlides` 插到锚点后。
- ProjectShell 已有网格底时，Board 画布可再叠一层 **dot** 径向点阵，强化白板感。
