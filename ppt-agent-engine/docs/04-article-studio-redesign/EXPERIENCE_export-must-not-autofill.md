# EXPERIENCE · 导出按钮不能偷偷当流水线

## 何时复用

- 「导出 / Download」会触发服务端 ensure / generate
- 多页文档，用户常只想预览当前页
- 产品有「全部自动生成」入口时，导出更不该重复承担全量补齐

## 原则

1. **导出 = 打包已有产物**；生成 = 用户显式点生成  
2. 缺页时：**提示 + 缩小范围**（当前页 / 已就绪页），不要默认 `fillMissing`  
3. API 用 `slideIds` + `fillMissing` 把「范围」和「是否补齐」拆开，避免前端只能二选一骗自己  

## 反模式

- 导出接口内部 `for (all slides) ensure*`  
- 按钮文案「一键」却跑完整 AI 流水线  
- 用主题模板 silently 填满未生成页还假装「导出成功」且不告知  

## 推荐默认

| 调用方 | fillMissing | slideIds |
|--------|-------------|----------|
| Studio 导出按钮 | `false` | 当前 / 已就绪 / 全部（全就绪时） |
| 运维/批处理脚本 | 按需 `true` | 通常省略（全部） |
