# 经验：看板「加页」必须带分组键

## 场景

一行一章的故事板/便利贴墙里，「加一页」若只追加空白实体、不写章节字段，UI 分组会把它当成新行（或「未分章」），用户以为坏了「加章节」。

## 可复用做法

1. **加页 ≠ 加章**：两个入口；加页传 `partTitle`（或 `afterSlideId` 继承），加章传**新** `partTitle`。
2. **插入位置由后端算 sortOrder**：只靠前端 create + reorder 容易漏写字段；`afterSlideId` 一次请求完成归属与顺序。
3. **合成章节卡无实体**：新章 = 至少一张带新 `partTitle` 的内容页；不要单独建「章节表」除非产品真要元数据。
4. **选中上下文喂顶栏**：侧栏/章节卡/内容卡统一 `BoardFocus`，无选中时落到最后一章末尾，避免顶栏加页漂到错误分组。

## 注意

- 连续分组：中间插入无 `partTitle` 的页会把一章拆成多行——回归时优先查创建载荷。
- 显示名「未分章」与库内 `null` 不同；API 继承锚点即可，不必强行写入「未分章」字符串（除非产品要固化该标签）。
