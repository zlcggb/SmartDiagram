# EXPERIENCE · Studio 主题配置侧栏 IA

## 何时复用

- 右侧「主题 / 样式」面板要学竞品交互，但底层是 **SVG 色值写死 + IR 版式生成**，做不到竞品级即时结构编辑
- 需要在「控制面板感」与「不欺骗用户」之间取舍

## 做法

1. **学 IA，不学皮肤**：分组（族 → 包 → accent → 质感 → 说明 → 导出），分段控件与短标签；保留本站浅色 design system。
2. **只暴露真实即时能力**：色板换色（`recolorSvgPreview`）、accent、CSS 质感滤镜；结构参数写清「需重新生成」，宁可不做假滑杆。
3. **预览与导出同色**：会话 accent 必须进导出 API，否则用户以为导出也带强调色。
4. **质感分层**：即时层 = CSS filter；构图层 = regenerateHint / 重新生成（可后续接提示词）。
5. **有限枚举**：ThemePack、accent、surface 都走 shared 单一来源，避免 UI 自由色盘。

## 反例

- 照搬「站点数量 / 上下交替」开关但 preview 不变 → 信任崩塌
- 只改预览 accent、导出不传 → 下载结果与所见不符
- 为学竞品换成深色霓虹整页换肤 → 与现有工作室视觉分裂
