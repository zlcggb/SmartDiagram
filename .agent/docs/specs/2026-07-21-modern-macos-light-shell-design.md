# DeepDiagram Pro 现代 macOS 浅色壳层设计

## 目标

将现有深色桌面全面转换为参考图 2/3 的现代 macOS 浅色 Aqua 体系：日间蓝湖山景壁纸提供色彩，菜单、Dock、窗口与所有弹层使用乳白、浅灰、蓝灰半透明材质。保留已实现的真实路由、数据和键盘交互。

## 视觉方向

- 原型：macOS Sonoma / Aqua 浅色桌面与 Finder 窗口。
- 设计锚点：“壁纸有色，界面中性”；所有交互容器用同一组浅色窗口材质。
- 差异点：保留 DeepDiagram 自有图标、真实项目和历史记录，不复制 Apple 专有图标或桌面文件。

## 桌面

- 使用原创 16:10 蓝湖、花岗岩和远山日间壁纸，不含文字、图标和水印。
- 左上小组件区参考真实 macOS：时钟/状态为半透明蓝灰，日历为乳白卡片，账户卡为浅色玻璃。
- 最近工作区改为浅色 Finder 式悬浮窗口，而不是黑色仪表板。
- 右侧保留思维导图、PPT 制作和最近项目图标，使用 macOS 桌面选中蓝色胶囊。

## 壳层与所有弹窗

- 菜单栏：30px 高的乳白透明玻璃，深色文字，与壁纸颜色混合。
- 下拉菜单：白色磨砂浮层，细描边，选中项使用蓝色底和白字。
- Dock：乳白透明胶囊，22–26px 圆角，保留已实现的平滑放大与自动隐藏。
- 统一窗口：白色工具栏、浅灰内容面、红黄绿交通灯、24px 圆角和扩散阴影。
- 以下全部必须统一浅色：关于、帮助、最近项目、登录、Spotlight、网络、控制中心、日历、用户中心、消息提示。
- 最近项目窗口采用 Finder 式浅蓝侧栏和白色内容区；Spotlight 使用可读的乳白玻璃搜索面板。

## 交互与数据

不改变现有功能契约：动态页面菜单、编辑命令、Spotlight 搜索、最近项目真实 API、桌面图标单击/双击/Enter、Dock 导航、系统面板和键盘焦点恢复全部保留。

## 响应式与可访问性

- 1440×900 和宽屏：完整桌面、小组件、最近工作窗口、右侧图标和 Dock。
- 1024×768：缩小小组件和主窗口，保持不重叠。
- 小屏：改为浅色 Launchpad 式卡片流，弹窗不超出视口。
- 文字对比、蓝色焦点环、键盘菜单、减少动效、增强对比和强制颜色模式保持可用。

## 验收

1. 首页不存在黑色主表面，壁纸为明亮日间蓝色自然景观。
2. 所有壳层菜单和弹窗的默认表面都是浅色，只在选中或警示状态使用高饱和色。
3. 参考图 2 验收整体色彩、层级和 Dock，参考图 3 验收窗口、侧栏、工具栏和圆角。
4. 在 1440×900 与 1024×768 完成浏览器截图，并打开菜单、Spotlight、最近项目、登录和系统弹层逐项检查。
5. 定向 lint、Shell 测试和生产构建通过，`design-qa.md` 最终为 `final result: passed`。
