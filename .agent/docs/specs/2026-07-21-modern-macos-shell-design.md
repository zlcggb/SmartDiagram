# DeepDiagram Pro 现代 macOS 深色壳层设计

## 1. 背景与目标

当前聚合首页已有菜单栏、桌面图标、小组件与 Dock，但尺寸、材质和交互不在同一套系统内。Dock 图标最大放大到 1.6 倍，造成严重重叠；顶部菜单和控制区则以无功能按钮为主，与“系统级桌面”的认知不符。

本次改造目标：

1. 在宽屏上还原现代 macOS 深色桌面的比例、层级、材质和动效。
2. 让菜单栏、桌面图标、Dock 和弹层与当前页面上下文相关。
3. 每个可点击控件都执行可验证的真实操作；没有真实状态或行为的项目不做成按钮。
4. 复用已有路由、认证、PPT 项目 API 与绘图历史 API，不创建假数据。

## 2. 设计方向

### 2.1 原型与差异点

- 原型：现代 macOS 深色桌面，强调克制、精密和清晰层级。
- 差异点：“真实可用的产品桌面”。Spotlight、最近项目、动态应用菜单与 Dock 均直接连接 DeepDiagram Pro 的真实功能。

### 2.3 壁纸

- 固定为石墨黑到深海蓝的抽象深色壁纸，以少量青蓝光带建立景深。
- 光带避开左上小组件和右侧图标区，中部保留负空间。
- 仅保留极轻颗粒与暗角，不再使用大面积模糊远山和发白湖面。
- 聚合段固定为深色风格，不跟随浅色系统外观切换成白昼壁纸。

## 3. 信息架构与组件

### 3.1 菜单栏

- 高度 30px，使用深色半透明材质和 24px 至 32px 背景模糊。
- 左侧为品牌图标、当前应用名、当前应用可用菜单。
- 右侧为真实网络状态、控制中心、Spotlight、日期时间和用户中心。
- 菜单支持鼠标、方向键、Escape 关闭和焦点返回。
- 同一时间只允许一个菜单或系统弹层打开。

### 3.2 页面动态菜单

#### 桌面

| 菜单 | 命令 | 真实行为 |
| --- | --- | --- |
| DeepDiagram Pro | 关于 | 打开关于窗口 |
| DeepDiagram Pro | 登录或退出登录 | 调用现有认证 store |
| 文件 | 打开思维导图 | 导航到 /diagram |
| 文件 | 打开 PPT 制作 | 导航到 /ppt |
| 文件 | 最近项目 | 打开真实项目窗口 |
| 显示 | 显示或隐藏小组件 | 更新桌面设置 |
| 显示 | 显示或隐藏桌面图标 | 更新桌面设置 |
| 显示 | 进入或退出全屏 | 调用 Fullscreen API |
| 前往 | 桌面、思维导图、PPT 制作 | 路由导航 |
| 帮助 | 键盘操作 | 打开快捷键说明 |

#### 思维导图

| 菜单 | 命令 | 真实行为 |
| --- | --- | --- |
| 文件 | 新建绘图会话 | 调用 chatStore.clearMessages 并重置画布上下文 |
| 文件 | 打开绘图历史 | 打开现有历史面板并读取真实图表或会话 API |
| 显示 | 浅色或深色画布 | 调用 chatStore.setCanvasMode |
| 显示 | 聚焦对话或画布 | 移动端切换现有 mobileActivePanel，桌面端聚焦对应区域 |
| 前往 | 桌面或 PPT 制作 | 路由导航 |
| 帮助 | 绘图操作说明 | 打开快捷键和操作说明 |

若撤销、重做或导出无法通过当前所有绘图引擎一致执行，则不放入壳层菜单，仍使用画布自身工具栏。

#### PPT 制作

| 菜单 | 命令 | 真实行为 |
| --- | --- | --- |
| 文件 | 新建演示项目 | 导航到 /ppt 并聚焦新建输入区 |
| 文件 | 我的项目 | 导航到 /ppt#recent-projects 并聚焦真实项目列表 |
| 项目 | 需求、结构、设计、导出 | URL 包含项目 ID 时进入对应工作区 |
| 显示 | 进入或退出全屏 | 调用 Fullscreen API |
| 前往 | 桌面或思维导图 | 路由导航 |
| 帮助 | PPT 工作流说明 | 打开与当前阶段匹配的说明 |

PPT 项目列表继续通过 api.listProjects 获取，新建项目继续调用 workbenchStore.createProject。

### 3.3 桌面小组件

- 时钟和日历为两个紧凑正方形，宽屏基准尺寸 148px。
- 账户组件宽度 312px，文案仅保留用户、工作空间和一个主操作。
- 时钟按秒更新，日历按真实当月计算。
- 登录按钮调用现有 authStore.openLogin；已登录时显示真实用户。
- 小组件可由“显示”菜单和控制中心显示或隐藏。

### 3.4 桌面图标

- 图标视觉尺寸 56px，点击区不小于 76px × 84px。
- 单击选中，双击或 Enter 打开，符合桌面语义。
- 思维导图和 PPT 制作打开真实模块路由。
- 最近项目打开 Finder 风格窗口，分为 PPT 项目与绘图历史。条目使用真实标题、类型和更新时间，可进入项目或恢复会话。
- 选中状态使用 macOS 蓝色文字胶囊和轻微压暗，不缩放整个图标。

### 3.5 Dock

- 基础图标 46px，最大放大 1.25 倍，影响半径约 110px。
- 图标间距 8px，水平内边距 10px，垂直内边距 7px，圆角约 18px。
- 放大使用平滑衰减并最多上移 8px，不得越出视口或严重覆盖相邻图标中心。
- 首页默认显示；模块内默认自动隐藏，鼠标到达底边时显示。
- 控制中心可切换 Dock 自动隐藏，偏好写入 localStorage。
- 点击 Dock 图标立即导航；当前应用显示小型指示点。

### 3.6 右上角系统区

#### 网络状态

- 使用 navigator.onLine 与 online、offline 事件展示真实浏览器网络状态。
- 点击显示状态面板，说明是否在线及其对 AI 生成和项目同步的影响。
- 不显示伪 Wi-Fi 名称，不保留无数据来源的电池按钮。

#### 控制中心

仅包含有真实实现的能力：

- 显示或隐藏桌面小组件。
- 显示或隐藏桌面图标。
- Dock 自动隐藏。
- 进入或退出浏览器全屏。

不伪造系统音量、蓝牙、专注模式等能力。

#### Spotlight

- 点击放大镜或按 Meta/Ctrl + K 打开。
- 搜索应用入口、PPT 项目，以及登录用户的绘图或会话历史。
- 结果按应用、PPT 项目、绘图历史分组，支持上下键和 Enter。
- 未登录时仅搜索应用入口，并提供可执行的登录结果。
- 项目 API 加载失败不影响应用入口搜索，错误在对应分组显示。

#### 日期与用户

- 点击日期时间打开真实当月日历。
- 未登录时用户入口打开现有登录窗口。
- 已登录时显示真实用户名、邮箱与退出操作。

### 3.7 统一窗口和弹层

- 登录、最近项目、关于和帮助使用同一个 macOS 窗口容器。
- 红色控制点关闭；黄色控制点在支持时最小化；绿色控制点在支持时切换大尺寸。
- 不支持的控制点显示为不可用，不伪装可点击。
- 打开后焦点进入窗口；Escape 关闭；关闭后焦点返回触发元素。

## 4. 状态与数据流

壳层增加小型桌面 UI store，仅保存：

- 当前打开的菜单、系统弹层或窗口。
- 小组件可见性。
- 桌面图标可见性。
- Dock 自动隐藏偏好。
- 当前选中的桌面图标。

数据边界：

- 认证状态继续来自 usePlatformAuth。
- PPT 项目继续来自 frontend/src/ppt/lib/api.ts 的 api.listProjects。
- 绘图历史复用 ChatPanel 已有端点与恢复逻辑，并提取为共享类型和 API 封装，避免在壳层复制请求细节。
- localStorage 只保存纯 UI 偏好，不保存项目、会话或认证秘密。

## 5. 响应式行为

| 视口 | 行为 |
| --- | --- |
| 1180px 及以上 | 完整桌面：左侧小组件、右侧图标、完整菜单栏、Dock |
| 768px 至 1179px | 小组件紧凑化，隐藏低优先级菜单文字，保留应用、Spotlight 和系统区 |
| 768px 以下 | 首页改为 Launchpad 式入口；顶部仅保留品牌、时间、搜索和用户；Dock 不覆盖模块内容 |

任何尺寸下都必须保证 Dock 不覆盖主操作、弹层不越界、图标与小组件不重叠，且菜单文字不与系统区重叠。

## 6. 错误处理

- 项目或历史 API 加载失败：在对应窗口分组内显示错误和重试，不关闭整个窗口。
- 未登录导致历史不可用：显示登录操作，不用空白列表伪装“无项目”。
- Fullscreen API 不可用或被拒绝：显示非阻塞通知并恢复开关。
- PPT 项目 ID 缺失时禁用项目级菜单并说明原因，不导航到无效 URL。

## 7. 可访问性与动效

- 所有图标按钮必须有中文 aria-label。
- 菜单使用 menu 和 menuitem 语义，可通过键盘完整操作。
- 键盘焦点使用克制但清晰的蓝色焦点环。
- 文字与玻璃表面保持可读对比。
- 菜单打开约 140ms，窗口约 220ms，Dock 回落约 180ms。
- 遵循 prefers-reduced-motion，不使用无功能意义的循环动画。

## 8. 验证与验收

### 8.1 自动验证

1. TypeScript 类型检查和生产构建通过。
2. 命令映射测试覆盖桌面、思维导图、PPT 首页和 PPT 项目页。
3. 菜单关闭、键盘导航、焦点恢复和 Dock 偏好持久化通过组件测试。
4. Spotlight 在 API 成功、失败和未登录三种状态下均可用。

### 8.2 浏览器验证

1. 在至少 1440×900、1024×768 和一个手机视口下截图检查。
2. Dock 默认、悬停和边缘图标放大状态不得严重互相覆盖。
3. 菜单栏没有无效按钮；每个命令都产生导航、状态变化、弹层或数据加载结果。
4. 桌面图标的单击、双击、Enter 和空白区取消选中符合预期。
5. 最近项目和 Spotlight 显示真实数据，可打开项目或恢复绘图会话。
6. 登录前后的菜单、账户组件和用户面板状态一致。

## 9. 实施边界

本次包含：

- 首页壁纸、小组件、桌面图标与响应式改造。
- AppShell 菜单栏、系统区、弹层与 Dock 改造。
- 最近项目、Spotlight、关于、帮助和控制中心实际功能。
- 为壳层命令提取必要的 PPT 项目与绘图历史共享 API。

本次不包含：

- 改写思维导图引擎或 PPT 生成流程。
- 伪造系统音量、蓝牙、电池或通知中心。
- 在浏览器中复制真实 Finder 文件系统。
- 与壳层无关的后端、PPT 渲染器或绘图引擎重构。
