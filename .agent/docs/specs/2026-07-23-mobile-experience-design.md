# SmartDiagram 全站移动端体验设计

## 目标

在不改变桌面端信息架构和 Aqua 视觉语言的前提下，为 360–620px 宽度建立完整、可触控、无横向溢出的移动端体验。覆盖桌面首页、图表工作区、PPT 首页、PPT 项目的意图/结构/工作室/导演页面，以及它们共用的菜单、弹窗和 Dock。

## 设计方向

采用“极简精致的 Aqua 移动工作台”。保留壁纸、半透明材质与应用 artwork，但降低玻璃叠层数量，用更明确的字号、间距和表面层级提升信息效率。

标志性锚点是新的移动顶栏：`桌面图标 + 当前模块名 + 更多菜单 + 头像`。桌面端的文件、编辑、显示、前往、窗口和帮助菜单在手机上收纳进“更多”弹层，避免顶栏重叠。

## 响应式规则

- 主要断点：`620px`；极窄屏补充断点：`390px`。
- 移动端使用 8px 间距节奏，页面水平安全边距 12–16px。
- 主要触控目标不小于 44px；纯图标按钮不小于 40px，并保留可访问名称。
- 页面不得产生意外横向滚动。必要的画布、时间轴或表格应在自身容器中明确横向滚动。
- 固定底部控件使用 `env(safe-area-inset-bottom)`；内容区预留 Dock/Tab Bar 的遮挡空间。
- 输入框字号不小于 16px，避免 iOS 聚焦缩放。

## 页面设计

### 共用 Shell

- 移动端顶栏高度 48px，模块标题单行截断。
- “更多”按钮打开包含原顶层菜单的移动菜单；子项仍复用现有命令和禁用状态。
- 状态类功能保留网络、搜索、控制中心和账户入口，但在移动菜单中呈现，顶栏只保留账户头像。
- 系统弹层宽度限制在视口内，并从顶栏下方展开。
- Dock 固定于安全区上方，图标按视口自动缩放，关闭悬浮放大和 tooltip，保证内容底部留白。

### 桌面首页

- 时钟和日历保持等宽双列，不再横向滚动；窄屏按可用宽度等比缩放。
- 账户卡压缩身份区和说明，按钮满足触控尺寸。
- 最近工作改为单列紧凑列表：应用图标、类别、标题、摘要和时间形成稳定的阅读顺序。
- 工作区操作按钮在标题下方或右侧自适应换行。

### 图表工作区

- 保留现有聊天/画布双 Tab 模式，确保顶部工具与底部 Tab 不遮挡内容。
- 聊天输入、历史记录、设置和导出弹层在手机上占满可用宽度。
- 画布工具允许局部滚动或折叠，不压缩主画布到不可用尺寸。

### PPT 首页

- Hero、创建表单、模板/最近项目从多列切换为单列。
- 表单控件、项目操作和筛选器允许换行，卡片内容不截断关键操作。

### PPT 项目工作区

- 项目头部与阶段导航变成可横向滚动的紧凑导航，保留当前阶段可见性。
- 意图、结构、工作室和导演页面在移动端统一单列；侧栏/属性面板转为内容下方或可滚动分区。
- 幻灯片预览保持 16:9 比例，编辑/操作区不与预览重叠。

## 状态与错误

- Loading、空状态和错误提示必须在 360px 下完整显示。
- 弹窗使用 `max-height` 和内部滚动，不让操作按钮落到视口之外。
- reduced motion、reduced transparency 和 forced colors 规则继续生效。

## 验收标准

- 360×800、390×844、430×932、606×1494 视口下无页面级横向溢出。
- 顶栏文本不重叠；移动菜单可打开并触发既有命令。
- 底部固定元素不遮挡最后一项内容。
- 所有主要按钮可触控，表单聚焦不会导致布局异常。
- TypeScript 构建、现有 shell 测试和 lint（若无既存阻塞）通过。
- 对所有可直接访问的页面和可获得测试数据的项目子路由完成真实浏览器截图检查。
